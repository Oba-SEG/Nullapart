# Nullapart Mail Contracts

Core domain types and contracts for the mail system.

## Contracts

- SMTP Transaction
- Tenant Message Instance
- Security Finding
- Policy and Configuration
- Artifact
- Event
- Audit
- API Error

## Usage

```toml
[dependencies]
nullapart-mail-contracts = { path = "../crates/mail-contracts" }
```
