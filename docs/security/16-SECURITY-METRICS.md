# Security Metrics

Security metrics detect control degradation and improve decisions.

## Identity/access

Track MFA coverage, phishing-resistant MFA for privileged staff, System/Support admin counts, dormant privileged accounts, access-review completion and break-glass use.

## Vulnerability management

Track open Critical/High findings, age, patch-SLA compliance, known-exploited vulnerabilities and scan coverage.

## Audit

Track audit write failures, checkpoint/archive failures, exports, high-risk admin actions and impersonation sessions.

## Mail security

Track required scanner availability, UNKNOWN/ERROR rate, malware/phishing/BEC detections, false-positive release rate, confirmed false negatives, queue depth/age, post-delivery threats and outbound-abuse incidents.

## Secrets/crypto

Track certificates nearing expiry, secrets beyond rotation targets, failed rotations, revoked identities and DKIM/TLS key age.

## Incident response

Track incident count/severity, time to detect/contain/recover and overdue corrective actions.

## Backup/DR

Track backup success, restore-test success, last restore exercise and achieved RPO/RTO.

## Reporting

System Admin security dashboard should surface relevant control-health metrics without exposing secrets or customer content.
